# 📊 Sales Analysis Dashboard

## 📌 Project Overview

The **Sales Analysis Dashboard** is an interactive Power BI project developed to analyze sales performance, revenue trends, product performance, customer segments, and regional sales.

The dashboard transforms raw sales data into meaningful business insights through interactive visualizations and KPIs.

## 🛠️ Tools & Technologies

* Microsoft Excel
* Power Query
* Power BI
* DAX
* Data Cleaning
* Data Transformation
* Data Visualization

## 🎯 Key KPIs

* 💰 Total Sales
* 📦 Total Orders
* 👥 Total Customers
* 📈 Total Profit
* 📊 Profit Margin
* 🛒 Average Order Value

## 📈 Key Analysis

The dashboard provides analysis of:

* Sales by Month
* Sales by Category
* Sales by Sub-Category
* Sales by Product
* Sales by Region
* Sales by Customer Segment
* Profit by Category
* Sales and Profit Trends
* Top-performing Products
* Regional Performance
