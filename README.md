# 📊 Sales Analysis Dashboard

## 📌 Project Overview

The **Sales Analysis Dashboard** is an interactive Power BI dashboard designed to analyze sales performance and provide meaningful business insights.

The dashboard presents key metrics such as Total Revenue, Total Orders, Average Order Value (AOV), and Average Discount. It also enables analysis based on product categories, age groups, payment methods, months, cities, gender, and device types.

## 🛠️ Tools & Technologies

- Microsoft Excel – Data source and preparation
- Power Query – Data cleaning and transformation
- Power BI – Dashboard development and visualization
- DAX – KPI and measure calculations
